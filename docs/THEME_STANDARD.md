# TrailViewer 主题开发与视觉一致性标准

本标准用于约束 TrailViewer 所有现有与未来主题的视觉架构、交互状态、宿主联动与验收流程，确保每次新增或调整主题都能**一次性全局同步**，杜绝零散补丁、按钮态遗漏、对比度不足或装饰泄露。

---

## 1. 单一语义令牌契约

所有 UI 组件（工具栏、摘要卡、分段表、剖面图、图层菜单、航点列表/筛选浮窗、工具箱全子页、轨迹编辑器）必须只消费 `viewer/css/tokens.css` 中的语义令牌，禁止在组件样式里散落硬编码色值。

每个主题块（`:root[data-theme="<id>"]`）必须完整定义以下 5 组核心令牌：

### 1.1 表面四层级

| 层级 | 核心令牌 | 适用场景 | 一致性约束 |
| --- | --- | --- | --- |
| **常驻浮层** | `--panel`、`--hud-shadow` | 摘要卡、分段面板、海拔剖面 | 与浮窗菜单保持同一材质语言 |
| **浮窗与弹出层** | `--tool-panel-background`、`--tool-panel-filter` | 工具箱、图层菜单、航点列表、航点筛选/纠偏浮窗 | 弹出层禁止退回不透明实底（除非主题本身为实底） |
| **内嵌卡片与行** | `--surface-card`、`--surface-row`、`--surface-inset` | 快捷工具格、气象卡、列表滚动区 | 玻璃主题下避免高不透明叠层导致发浑 |
| **交互控件底** | `--surface-control`、`--surface-input`、`--surface-hover` | 选项按钮、输入框、分段切换、清空按钮 | 常态与悬停态必须具备清晰亮度阶差 |

### 1.2 强调色双轨分离

为了杜绝浅亮强调色（如冰蓝）与白色主按钮文字冲突，必须严格分离两条强调色轨道：

- **装饰与描边强调色（`--accent` / `--accent-text` / `--icon-active-line`）**：用于信息卡左侧竖线、选中态边框、底栏色卡选中外圈、剖面游标与照片缩略图高亮框。全站所有同类指示必须统一使用同一色系，禁止同屏混用两种蓝。
- **主按钮填充色（`--btn-primary-bg` / `--btn-primary-hover` / `--btn-primary-border` / `--btn-primary-text`）**：专用于高优先级实心操作按钮（如「导出 PNG」「全部导出」「检查更新」「保存」「在气象站打开」），白字与底色对比度必须满足 WCAG AA（`>= 4.5:1`）。

### 1.3 按钮五态执行标准

所有可交互按钮（工具栏、缓存设置、图源节点、叠加层芯片、航点筛选、工具箱主页及 6 个子页、编辑器按钮）必须完整覆盖以下 5 种状态：

| 状态 | 视觉要求 | 工程红线 |
| --- | --- | --- |
| **常态（Default）** | 使用 `--surface-control` / `--surface-card` + `--border-control` | 不得在后置主题覆写块中用高权重压过基础 `:hover` |
| **悬停（Hover）** | 底色与边框同步提亮，文字提至 `--text-bright`，带 `120ms` 过渡 | 必须限定 `:not(:disabled)`，且写在同权重常态规则之后 |
| **选中 / 开启（Selected）** | 统一切换为选中底色 + 强调色描边 + 粗体高亮文字 | 同页所有单选/开关按钮（含 `已开启`、节点、缓存、筛选）视觉一致 |
| **选中悬停（Selected Hover）** | 在选中底色上叠加轻度提亮，不丢失选中标识 | 禁止悬停时把选中按钮洗白或打回普通灰底 |
| **禁用（Disabled）** | 文字降至 `--icon-disabled` 或整体降透明，光标恢复 `default` | 禁止触发悬停变色和按压位移 |

### 1.4 圆角三阶梯与色卡锁定

- **顶层浮层圆角（`--panel-radius`）**：用于主信息卡、分段表、剖面图、工具箱与图层主面板。
- **顶部工具栏圆角（`--toolbar-radius`）**：用于缩放、定位、着色、工具箱、图源与航点按钮；常规图标按钮保持圆角矩形（如 `3px` / `8px` / `12px`），不强行做成正圆。
- **面板内控件圆角（`--control-radius` / `--radius-sm`）**：用于缓存选项、节点芯片、筛选按钮与子页表单按钮，同页保持统一弧度（仅独立状态徽章可使用 `--radius-pill`）。
- **底栏主题微缩色卡**：所有主题色卡严格锁定相同的外框尺寸（`17px × 15px`）与贴边顶条（`inset: 0 0 auto 0`），禁止用内缩亮框造成视觉偏小。

## 2. 明暗模式与宿主联动规范

每个主题必须明确归属以下三种明暗策略之一：

1. **固定深色**（如 `slate`、`classic`）：始终使用深色前景与 QuickLook 深色标题栏。
2. **固定浅色**（如 `swiss`）：始终使用深墨前景、浅色图标校准与 QuickLook 浅色标题栏。
3. **随底图自适应**（如 `ios`）：由 `layer-selection.js` 实时同步 `data-map-tone="dark" | "light"`：
   - **卫星图 / 无底图 / 暗色自定义图源**：走深态样式 + QuickLook 深色标题栏。
   - **路网 / 地形 / 浅色自定义图源**：走浅态样式 + QuickLook 浅色标题栏。

宿主标题栏联动要求：
- 仅切换 QuickLook 原生 `Themes.Light` / `Themes.Dark`，保留宿主默认标题栏底色遮罩，禁止关闭 `TitlebarColourVisibility` 导致浅色标题栏发黑。
- 冷启动时按持久化偏好预先设置标题栏与底板明暗，运行期间随主题和底图切换即时同步。

## 3. 装饰隔离与性能无障碍红线

- **白名单装饰隔离**：瑞士测绘专属装饰（四段比例尺、`1 : N` 分母、直角公里标、剖面极值三角标、刻度轴）只允许显式匹配 `:root[data-theme="swiss"], :root[data-theme="slate"]`，严禁对新装饰使用 `:not([data-theme="..."])` 反向选择器。
- **拖图无闪烁**：常驻摘要卡、海拔剖面、工具栏、工具箱、图层菜单与航点列表在地图拖动或点击定位时不得突然切换不透明黑/白底色造成闪烁。
- **对比度与无障碍**：正文、次要文字、主按钮文字与背景对比度满足 WCAG AA（`>= 4.5:1`）；所有动效遵守 `prefers-reduced-motion: reduce`。
- **渲染约束**：海拔剖面图禁止使用 SVG `<mask>` 或 CSS `mask-image`；超 8,000 点长轨迹的 Canvas 描边层必须响应 `refreshTheme()` 同步刷新。

## 4. 四端注册同步清单

新增或重命名任何主题时，必须同步更新以下 5 处，缺一不可：

1. `viewer/theme.js`：`THEMES` 常量列表。
2. `src/ViewerPreferences.cs`：`Allowed["theme"]` 白名单与 `ResolveHostTheme()` 宿主明暗映射。
3. `viewer/i18n.js`：英文与中文的 `theme.<id>` 及 `theme.<id>Hint`。
4. `viewer/css/tokens.css`：`:root[data-theme="<id>"]` 完整语义令牌块（若为自适应主题，同步补齐 `[data-map-tone="light"]` 块）。
5. `viewer/css/toolbox.css`：`.toolbox-theme-option[data-theme-option="<id>"]` 微缩色卡样式。

## 5. 自动校验与 7 面必检闭环

### 5.1 自动化守门命令

每次修改主题样式或新增主题后，必须执行：

```bash
npm run theme:check
```

脚本自动拦截以下问题：
- 前端、宿主、中英文文案、令牌块、色卡五处主题列表不一致；
- 任意主题缺失核心语义令牌；
- 正文 / 次文 / 主按钮文字对比度低于 WCAG AA（`4.5:1`）；
- 地图数据或工具箱中出现反向 `:not([data-theme=...])` 装饰选择器；
- 主题覆写按钮常态背景却缺少对应 `:hover` 规则。

### 5.2 实机 7 面必检路线

热装后在 QuickLook 中按固定顺序走一遍，全部无误方可发版：

1. **主画布与拖图**：检查摘要卡、海拔剖面、比例尺、公里标、轨迹与白边描边，按住拖图确认无闪烁。
2. **分段面板**：展开「每公里」，悬停顶栏确认整条高亮无右端缺口，核对表头与汇总行。
3. **图源与地图设置**：核对分类按钮、图源选中态、叠加层芯片、本地瓦片缓存（悬停 + 选中 + 清空）与图源节点芯片。
4. **航点列表与筛选浮窗**：点击航点确认无闪烁，打开筛选浮窗检查材质透度、悬停与选中描边。
5. **工具箱全子页**：逐一检查主页、气象卡、叠加图导出（选项 + 导出主按钮）、点位坐标、附件导出（全部 + 仅本地）、测距、检查更新与底栏色卡大小。
6. **轨迹编辑态**：核对编辑顶栏、侧边工具条、抽屉按钮与底部操作提示胶囊。
7. **深浅底图与标题栏联动**：切换卫星 ↔ 地形/路网，确认自适应玻璃与 QuickLook 顶部标题栏同步变色且文字清晰。
